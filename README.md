# Muhammad Farzaib Khan — Portfolio

A responsive, accessible static portfolio. No installation or build is required.

## Publish on GitHub Pages

1. Create a public repository named `jrvs98.github.io` in your GitHub account (or use it if it already exists).
2. Upload `index.html`, `style.css`, `favicon.svg`, and `.nojekyll` to the repository root. A ZIP must be extracted first.
3. Open Settings → Pages. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, and save.
4. After GitHub completes deployment, the portfolio will be available at https://jrvs98.github.io/.

A project repository also works; the site uses relative asset paths.

## Edit the page

Content is in `index.html`; colors, layout, and mobile styling are in `style.css`. All contact and repository links are ordinary links. No tracking, external fonts, JavaScript, or third-party assets are required.

Content is based on the supplied CV and GitHub profile. Performance claims are self-reported CV figures, not independently audited. The page deliberately excludes the phone number and full CV download. Review the public wording and email before publishing.
